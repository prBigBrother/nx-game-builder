## NX Game Builder 1.2.0

- Native SwiftUI game app builder for Apple silicon, macOS 15+.
- Offline toolchain setup: Python, .NET SDK, nxnative and shader/compression tools are included.
- English/Russian interface, native sidebar, stage progress and overall Dock progress.
- NSZ/XCZ input support and experimental profiles for unregistered games.
- Redistributable OFL text/controller fonts and third-party notices in the builder and generated apps.

Install the DMG, drag the app into Applications, and install bundled tools at first launch. Xcode and Metal Toolchain are required separately to build games. Game images and keys are not included.

This release is ad-hoc signed and is **not Apple-notarized**. Check the source and SHA-256 before your first-launch decision in macOS Privacy & Security. Experimental game support may require additional compatibility work.
