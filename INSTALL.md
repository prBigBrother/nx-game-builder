NX Game Builder — Apple silicon, macOS 15 or newer

1. Open the DMG and drag NX Game Builder into Applications.
2. Open the app. On first launch, choose Install bundled tools; no dependency download is needed.
3. Install/open Xcode and complete Apple's setup. Install Metal Toolchain when prompted.
4. Supply your own game image and keys, select the output folder, and choose Build & Install.

The default GitHub build is ad-hoc signed, not Apple Developer ID signed or notarized. macOS may block its first launch. Inspect the source and checksums before deciding whether to allow it through System Settings > Privacy & Security. The app does not disable Gatekeeper or change system security settings.

The app includes no games, DLC, keys, Nintendo firmware or system fonts. Runtime licensing does not grant rights to publisher game content. See THIRD_PARTY_NOTICES.md and the Licenses folder inside the app.
